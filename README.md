# StereoKit Shallow Water Simulation

Code here is largely based on Lisaryus's [Simulating Water Over Terrain](https://lisyarus.github.io/blog/posts/simulating-water-over-terrain.html), which I found to be nice simple implementation with a pretty good explanation!

https://github.com/user-attachments/assets/4607ebca-8664-4b80-bb35-c062b326c4fd

The code is pretty simple, and mostly just a fun project, so it's only lightly commented. Sorry! Hopefully it's simple enough to be interesting.

This project uses StereoKit v0.4 preview builds, and I've been using it a bit as one of my demo/testbed projects for v0.4.
